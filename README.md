# 麦当劳健身卡路里教练 🍔💪

> 健身也想吃麦当劳？这个 Skill 会根据你的身体数据和训练目标，用麦当劳**真实营养数据**帮你搭配出符合当日卡路里与蛋白质目标的套餐。

基于**麦当劳中国官方 MCP Server** 开发的参赛作品 —— 麦当劳程序员创意开发大赛。

---

## 介绍

减脂期 / 增肌期的健身人群在外食时，常常算不清"这顿麦当劳到底能不能吃、怎么点才达标"。本项目把两件事连起来：

1. **科学的营养目标**：用 Mifflin-St Jeor 公式计算你的基础代谢（BMR）与每日消耗（TDEE），再按健身目标（减脂 / 维持 / 增肌）给出每日及单餐的热量、蛋白质、脂肪、碳水目标。
2. **真实的麦当劳菜单**：通过麦当劳官方 MCP 的 `list-nutrition-foods` 工具获取 160+ 款餐品的真实营养成分，在单餐热量预算内搜索**高蛋白、控脂、控钠**的套餐组合并打分推荐。

所有营养数据均来自麦当劳官方 MCP，**不是估算、不是硬编码**。

## 目标用户

- 处于减脂 / 增肌 / 维持阶段，仍想吃麦当劳的健身人群
- 需要控制每日卡路里与蛋白质摄入的减重 / 塑形人群
- 想把麦当劳 MCP 能力接入自己 AI 助手（WorkBuddy / Cherry Studio / Cursor / Kiro 等）的开发者

## 功能亮点

- 🧮 **营养目标计算**：BMR / TDEE / 每日 + 单餐宏量营养目标（蛋白质、脂肪、碳水）
- 🛡️ **专业安全护栏**：热量不低于基础代谢、蛋白质按瘦体重/封顶、脂肪设每公斤下限、极端 BMI 提醒
- 🍔 **真实套餐推荐**：在热量预算内搭配真实麦当劳餐品，最大化蛋白质、控制脂肪与钠
- 🥇 **蛋白质密度优先**：推荐引擎按"每 100kcal 蛋白质"筛选候选，优先高蛋白餐品
- 🚫 **忌口过滤**：支持排除关键词（如"可乐""薯条"）
- 🔌 **直接调用麦当劳 MCP**：命令行一键运行，无需额外搭建服务
- ✅ **真机验证**：核心流程已对接线上麦当劳 MCP 实测通过

## 工作原理

```
用户身体数据 + 健身目标
        │
        ▼
 计算 BMR / TDEE / 单餐热量与宏量营养目标
        │
        ▼
 调用麦当劳 MCP: list-nutrition-foods  ──►  160+ 款真实餐品营养
        │
        ▼
 在热量预算内搜索高蛋白、控脂控钠组合并打分
        │
        ▼
 返回 Top-N 推荐套餐 + 营养解释
```

集成细节见 [MCP_INTEGRATION.md](./MCP_INTEGRATION.md)；Skill 能力清单（参数、输入输出）见 [SKILL.md](./SKILL.md)。

## 安装

```bash
git clone <本仓库地址>
cd mcd-fitness-calorie-coach

# 建议使用虚拟环境
python -m venv .venv && source .venv/bin/activate

pip install -r requirements.txt
```

### 配置 MCP Token

1. 前往麦当劳 MCP 开放平台 <https://open.mcd.cn/mcp>，登录后在控制台激活并复制你的 **MCP Token**。
2. 复制 `.env.example` 为 `.env`，填入你的 Token：

```bash
cp .env.example .env
# 编辑 .env，将 YOUR_MCP_TOKEN 替换为真实 Token
```

> ⚠️ **切勿将真实 Token 提交到仓库**。`.env` 已在 `.gitignore` 中忽略。

## 使用示例

### 运行

```bash
export MCD_MCP_TOKEN=你的Token   # 或写入项目根目录 .env，运行时自动加载

python main.py --gender male --age 28 --height 178 --weight 80 \
    --activity moderate --goal cut --meals 3 --exclude 可乐 雪碧
```

提供体脂率时，蛋白质按**瘦体重**计算，更精确（推荐给体脂偏高的人群）：

```bash
python main.py --gender male --age 40 --height 170 --weight 95 \
    --body-fat 30 --activity sedentary --goal cut
```

## 算法说明

> 本项目的营养与训练逻辑经健身教练 / 营养视角复核，加入了多项安全护栏。

- **BMR（Mifflin-St Jeor）**
  - 男：`10×体重(kg) + 6.25×身高(cm) − 5×年龄 + 5`
  - 女：`10×体重(kg) + 6.25×身高(cm) − 5×年龄 − 161`
- **TDEE** = BMR × 活动系数（1.2 ~ 1.9）
- **每日热量**：减脂约 80% TDEE、维持 100%、增肌约 112%
- **热量安全下限**（护栏）：减脂目标热量不低于 `max(BMR, 性别最低安全值)`（女 1200 / 男 1500 kcal），
  触发时上调并提示，避免长期低于基础代谢导致的代谢适应与肌肉流失。
- **蛋白质目标**：减脂 2.2 / 维持 1.8 / 增肌 2.0 g/kg
  - 提供**体脂率**（`--body-fat`）时按**瘦体重**计算，更精确（高体脂人群不再被高估）。
  - 未提供体脂率时按总体重估算，但施加 `2.4 g/kg` 与 `200g/天` 双重上限，避免高体脂人群蛋白虚高、碳水被挤占。
- **脂肪**：取 `max(占总热量 25%, 0.8 g/kg)`，设每公斤下限以保护激素健康；其余热量归碳水。
- **健康提示**（护栏）：对极端 BMI（<16 或 >40）、过小/过大年龄给出提醒。
- **推荐打分**：热量贴近预算（权重 0.9）+ 蛋白质达标（权重 1.1）− 脂肪超标惩罚 − 钠超标惩罚；
  同一餐品重复份数受限（饮品最多 1 份、其余最多 2 份），避免"两大杯饮料凑蛋白"等不合理搭配。
